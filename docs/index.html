统计和热量怎么来的？

同一条官网菜品记录里的同种食材只计一次。仅统计官网明确列出的食材，合并记录共用的食材只计一次。过敏原按食材表和菜名线索区分，配方不公开或有交叉接触时，仍需向食堂确认。

热量根据官网标注的重量，用参考值折算。部分成品使用同类食物类比。未公布的油、酱料及用量、骨头比例和实际打菜份量可能影响结果。
